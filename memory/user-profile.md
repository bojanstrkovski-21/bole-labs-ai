Bojan Strkovski (bojanstrkovski.21@gmail.com). Runs Arch Linux as primary OS
(boki setup). Works in Macedonian timezone (Europe/Skopje). Arch Linux power
user: comfortable with bash scripting, pacman internals, pkexec/polkit, and
AUR helpers (yay/paru).

Maintains a custom Arch Linux installer called archknife and a personal
pacman package repo (shtrkce-repo, shtrkce_repo_xl — hosted on GitHub Pages
at bojanstrkovski-21.github.io and mirrored on GitLab). Has an ArcoLinux
background (knows Nemesis repo, Erik Dubois' tooling) — distributes GUI
tools the way Erik Dubois does: plain `.py` files in `/usr/share/`, launched
via `pkexec`, no compiled binary needed. Comfortable reading and directing
code changes (including Python GUI code — Dear PyGui in particular) but
prefers to be explained what something does before changes are applied —
asks "what is it" before "fix it," and prefers checking a known-good
reference (e.g. Erik's repo) before accepting a fix outright. Works
incrementally, one feature at a time, confirming direction before
implementation.

Tool stack: nvim, kitty terminal, starship prompt, eza (ls replacement),
zoxide, fzf, carapace completions, NVM, Rust/cargo. Has xmonad, hyprland,
and chadwm setups. Runs a multi-distro portable bash config project
(arch/debian/fedora/opensuse/void alias files per distro), storing aliases
in `~/.config/bash_aliases/` with one file per distro.
